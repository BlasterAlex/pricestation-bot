# Повторная отправка уведомления о снижении цены

Задача на будущее. В этом изменении не делается.

## Что случилось

21 октября 2026 worker увидел скидку −20% на PRAGMATA и создал `price_drops`. В 12:10 UTC job уведомлений упал у всех подписчиков до вызова Telegram:

```text
AttributeError: 'str' object has no attribute 'tzinfo'
worker/tasks/notify.py → format_game_card → _format_offer_end
```

`discount_end` передавался строкой `strftime`, а форматтер карточки ждёт `datetime`. В логе: `Notified 0 user(s) for game_id=24 'PRAGMATA'`, `sent=0`. Сразу после этого дроп получил `notified_at`. Повторной отправки не было. Та же ошибка в том запуске закрыла дропы Shadow of Mordor и Red Dead Redemption 2.

Падение на дате уже исправлено: в карточку уходит `datetime`. Поведение «ошибка всё равно закрывает дроп» оставлено специально.

## Почему дроп нельзя просто оставлять открытым

`send_notifications` ставит `notified_at` на весь дроп, даже если кому-то сообщение не ушло. Так сделано, чтобы не слать карточку повторно тем, кто её уже получил.

Если при любой ошибке не ставить `notified_at`:

- дроп висит без срока, job идёт каждые 4 часа (`NOTIFY_CRON`, после окна `NOTIFY_AGGREGATION_HOURS`);
- в следующий запуск карточка уходит снова всем подписчикам, включая тех, кому уже доставлена;
- постоянная ошибка одного человека (бот заблокирован, пользователь недоступен) не заканчивается никогда.

Отдельной отметки «этому пользователю уже отправили» нет. Лимита попыток тоже нет.

## Что нужно

Таблица `price_drop_deliveries`. Строка значит «этому подписчику по этому дропу больше не шлём». Нет строки — пробуем в следующий запуск.

| колонка | тип |
|---|---|
| `id` | integer, PK |
| `price_drop_id` | FK `price_drops.id`, NOT NULL |
| `user_id` | FK `users.id`, NOT NULL |
| `outcome` | `varchar(16)`, NOT NULL: `sent` или `skipped` |
| `created_at` | `timestamptz`, NOT NULL, default `now()` |

Уникальный индекс `(price_drop_id, user_id)`.

- `sent` — сообщение ушло.
- `skipped` — Telegram ответил, что бот заблокирован или пользователь недоступен. Этому человеку не повторяем и дроп из-за него не держим.
- Любая другая ошибка (баг форматирования, сеть, лимит Telegram, слишком длинная подпись) строку не пишет. Повтор только этому подписчику.

`price_drops.notified_at` ставится, когда у каждого текущего подписчика есть строка, либо слать нечего: нет пересечения регионов или нет цены. Пока у кого-то строки нет, дроп открыт.

Уже закрытый дроп PRAGMATA (id 118, `notified_at` = 2026-10-21 12:10 UTC) сам в очередь не вернётся.
